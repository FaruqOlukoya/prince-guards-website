# Prince Guards - Professional Security Services Website

A modern, responsive website for Prince Guards, a leading security services provider in Nigeria.

## 🛡️ About Prince Guards

Prince Guards provides comprehensive security solutions including manned guarding, event security, VIP protection, surveillance, and more. With over 15 years of experience, we deliver professional security services you can trust.

## ✨ Features

- **Multi-page Website**: Home, About, Services, and Contact pages
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with royal blue branding
- **Interactive Elements**:
  - Auto-advancing services carousel
  - Animated statistics counter
  - Full-screen mobile navigation menu
  - WhatsApp integration for instant contact
- **Client Showcase**: Displaying trusted partner companies
- **Professional Leadership Section**: Meet our CEO and team

## 🚀 Technologies Used

- **React** - Frontend framework
- **React Router** - Client-side routing
- **Tailwind CSS v4** - Styling and responsive design
- **Vite** - Build tool and development server
- **TypeScript** - Type-safe code
- **Lucide React** - Modern icon library

## 🛠️ Development

### Prerequisites

- Node.js (v18 or higher)
- pnpm package manager

### Installation

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build
```
